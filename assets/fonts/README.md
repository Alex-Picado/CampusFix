# Trueno

CampusFix bundles the unmodified Regular, SemiBold and Bold faces from the
[Font Library Trueno archive](https://fontlibrary.org/api/catalogue/trueno/download).
The archive supplies the SIL Open Font License and FONTLOG included here.

| Upstream file | Bundled file |
| --- | --- |
| TruenoRg.otf | Trueno-Regular.otf |
| TruenoSBd.otf | Trueno-SemiBold.otf |
| TruenoBd.otf | Trueno-Bold.otf |
