# Delivery demonstration script

Use the pinned tools and isolated demo accounts in [Local evidence](local_evidence.md).
Do not display credentials or private records. Photograph fixtures are synthetic.

| Time | Demonstration | Expected observation |
| --- | --- | --- |
| 0-1 min | Introduce roles and local/public photograph modes | State the explicit delivery limitation. |
| 1-2 min | Register/sign in; profile and own reports | Reporter navigation and authorized reports. |
| 2-4 min | Create report and attach a local photograph | Confirmed consecutive, REPORTADA and acknowledged photo. |
| 4-6 min | Administrator classifies and assigns | Category/priority before assignment; ASIGNADA. |
| 6-8 min | Technician starts and records progress | EN_ATENCION, author/date/comment and optional photo. |
| 8-9 min | Resolve and administrator closes | Required solution; RESUELTA then CERRADA and audit trail. |
| 9-10 min | Search and combine filters | Consecutive/text/category plus state, priority and technician. |
| 10-11 min | Indicators and inactive categories | Global counts independent of filters; historical names preserved. |
| 11-12 min | Tablet, protected-route reload and role isolation | Adapted navigation; recovered detail; unrelated user denied. |
| 12-13 min | Public text-only mode and verification record | Clear photo notice; distinguish executed and pending checks. |

Existing phase 5 browser images document both completed workflows. Before a
published demonstration, obtain deployment authorization, apply reviewed rules
and indexes, record the actual Hosting URL and repeat the three-role walkthrough
there. Record revision, date, navigation and reload results. Alex's review and
merge are separate from local preparation.
